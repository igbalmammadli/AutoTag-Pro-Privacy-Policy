1. Information We Process & Operational Architecture

AutoTagPro adheres to strict data minimization and privacy-by-design principles. The application is an in-process plugin for Autodesk® AutoCAD® and operates under the following conditions:

  • Zero CAD / Drawing Data Transmission: All auto-numbering, balloon tagging, multi-leader styling, BOM table generation, gap detection, sequence synchronization, and Excel (.xlsx) exports occur strictly on your local machine. Drawing entity metadata (such as item names, part numbers, capacities, models, and custom fields) is stored directly in the active AutoCAD drawing database (.dwg) using standard AutoCAD extension dictionaries / XData. No drawing content or proprietary design data is ever transmitted externally.
  • Local User Preferences: Configuration settings (such as text size, bubble shapes, prefix formats, zero padding, layer names, and custom field labels) are stored exclusively on your local workstation at %LOCALAPPDATA%\AutoTagPro\config.json. This configuration is solely utilized by your local AutoCAD session and is never uploaded or shared.
  • Excel / BOM Exports: When you execute the ATAGBOMXLSX command to export a Bill of Materials spreadsheet, the resulting .xlsx file is written directly and exclusively to the local or network file path you choose. AutoTagPro does not inspect, copy, or transmit exported files.
  • No Telemetry or Tracking: AutoTagPro does not contain any analytics SDKs, tracking beacons, diagnostic uploaders, or background telemetry services. It does not monitor user behavior, keystrokes, or AutoCAD command invocation habits.
  • No Network Communication: AutoTagPro is a completely self-contained offline tool. Normal plugin operations perform zero outbound network requests to any developer or third-party servers.

3. Data Retention & Deletion

Because AutoTagPro does not collect or store your personal data on external servers, retention is fully under your control:

  • Local Configuration Removal: You can purge all local plugin settings at any time by deleting the folder %LOCALAPPDATA%\AutoTagPro.
  • Drawing Metadata: Tag data and metadata embedded within CAD files remain entirely within your .dwg files and can be modified or cleared using the built-in ATAGCLEAR command or standard AutoCAD commands.
  • Uninstallation: Uninstalling AutoTagPro via Windows Control Panel / Add-Remove Programs completely removes the application binaries and add-in manifest from your computer.

4. User Rights & Legal Compliance (GDPR & CCPA/CPRA)

AutoTagPro complies fully with international privacy regulations, including the European General Data Protection Regulation (GDPR) and the California Consumer Privacy Act (CCPA/CPRA).

Because we do not collect or maintain a database of personal data or telemetry from plugin users, no user profiles exist to access, sell, or disclose. You retain 100% ownership and sovereignty over your engineering drawings and files.
